' ============================================================
' Programa 6.3
' Programa para el test de Goldfeld & Quandt
' (pp. 411-413)
' ============================================================
'Programa para detectar la presencia de heterocedasticidad
'sobre la base del estadistico de Goldfeld & Quandt.
' ============================================================
'USO:
'   Programa creado para un archivo de trabajo "undated".
'   El nombre de la variable dependiente y el de
'   la variable escala deberan pasarse como los
'   dos primeros argumentos del programa.
'   Si la variable escala es una
'   transformacion de alguno de los regresores
'   originales, debera crearse una nueva serie
'   que contenga dicha transformacion.
'      Ejemplo:
'      GENR X2_2 = X2^2
'      X2_2 seria el segundo argumento del programa.
'   Debera crearse un grupo llamado Indep que
'   contenga a todos los regresores del modelo.
'   Debera elegirse el numero de observaciones
'   laterales (!m).
'
' ============================================================

!m = 50
SMPL @ALL
GENR _Dep = %0
!n = @ROWS(_Dep)
GENR _Orden = @TREND

TABLE(7,2) ResultGyQ_%1
ResultGyQ_%1(1,1) = "Test de Goldfeld & Quandt"
SETCOLWIDTH(ResultGyQ_%1,1,15)
SETLINE(ResultGyQ_%1,2)
ResultGyQ_%1(3,1) = "Var. escala"
ResultGyQ_%1(3,2) = %1
ResultGyQ_%1(4,1) = "Obs. laterales"
SETCELL(ResultGyQ_%1,4,2,!m,0)
SETLINE(ResultGyQ_%1,5)
ResultGyQ_%1(6,1) = "F_stat."
ResultGyQ_%1(7,1) = "F_prob."

SORT %1

'Primera regresion auxiliar.
' ============================================================
SMPL 1 !m
EQUATION _Temp1.LS %0 c Indep
!Ssr1 = _Temp1.@SSR

'Segunda regresion auxiliar.
' ============================================================
'Cuidado con la definicion de limites para la
'segunda regresion.
!lim=!n-!m+1
SMPL !lim !n
EQUATION _Temp2.LS %0 c Indep
!Ssr2 = _Temp2.@SSR

'Reponemos el orden.
' ============================================================
SORT _Orden
SMPL @ALL

'Construccion y reporte de estadisticos.
' ============================================================
!GyQ=!Ssr2/!Ssr1
!ProbGyQ=@FDIST(!GyQ,!m-_Temp2.@NCOEF,!m-_Temp1.@NCOEF)

SETCELL(ResultGyQ_%1,6,2,!GyQ,5)
SETCELL(ResultGyQ_%1,7,2,!ProbGyQ,5)

'Eliminamos los objetos temporales.
' ============================================================
D _Orden
D _Temp1
D _Temp2
D _Dep

'Fin del programa.
